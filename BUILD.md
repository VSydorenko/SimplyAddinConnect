# Инструкция по сборке проекта SimplyAddinConnect

## Требования
- CMake 3.12 или выше
- Visual Studio 2019 или выше с установленным компонентом "Разработка классических приложений на C++"
- Git

## Рекомендуемые шаги для правильной сборки

### 1. Клонирование репозитория
```bash
git clone https://github.com/yourusername/SimplyAddinConnect.git
cd SimplyAddinConnect
```

### 2. Создание отдельной директории для сборки
Чтобы избежать создания файлов сборки в корне проекта, всегда используйте отдельную директорию для сборки:

```bash
mkdir build
cd build
```

### 3. Конфигурация проекта с помощью CMake

#### Для x86 (32-bit) версии:
```bash
cmake -A Win32 ..
```

#### Для x64 (64-bit) версии:
```bash
cmake -A x64 ..
```

### 4. Сборка проекта
```bash
cmake --build . --config Release
```

или

```bash
cmake --build . --config Debug
```

### 5. Выходные файлы
После успешной сборки, выходные файлы будут находиться в директории `bin/Release` или `bin/Debug` корня проекта.

## Особенности сборки

- Большинство библиотек компилируются как статические (.lib), а не как динамические (.dll).
- Библиотека byte-array собирается как статическая библиотека по умолчанию.

## Диагностика ошибок

Если вы видите ошибку о несоответствии архитектуры (например, библиотека x64 используется для сборки x86), убедитесь, что:
1. Вы используете правильную версию библиотеки libcurl в зависимости от целевой архитектуры
2. Вы выбрали правильную архитектуру при конфигурации CMake

## Примечание по работе CMake

Чтобы избежать создания директории CMakeFiles в корне проекта, всегда запускайте CMake из отдельной директории сборки, как указано в инструкциях выше. Это обеспечит правильную организацию файлов сборки и предотвратит засорение корня проекта.
